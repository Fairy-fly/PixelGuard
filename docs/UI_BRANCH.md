# UI 开发分支

源自独立 PixelGuard-UI 副本，包含 Studio 工作台、ImageViewer 的滚轮缩放/拖动/适应窗口/100%、原图和红框结果切换。DiffDetector 和 ImageIO 逻辑保持稳定版原样。

本分支未合并到 main，程序版本仍沿用原开发副本0.2.0，不为未独立版本化的开发分支添加发布标签。既有设计记录涉及第三方参考图和私人截图，因此未上传；公开回归只使用合成数据。普通主窗口/查看器交互由 tests/ui_tests.cpp 覆盖。

README 中关于 main 的稳定功能说明不代表本开发分支已经发布。后续提升为稳定版本前应完成专门版本号更新、便携包重验及人工交互审阅。

本次发布整理后的开发分支已实际 Release 编译、CTest 5/5通过（17.08秒）。包含放大、缩放拖动、结果切换、完整导入检测保存和状态失效回归。未做新的便携包验收/物理多屏/长期压力验证，所以保持开发分支。
